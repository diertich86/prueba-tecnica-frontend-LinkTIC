# Prueba Técnica — Frontend - LinkTic

Gestión de métodos de pago construida con **Vue 3**, **Quasar** y **Pinia**.

## Stack

- Vue 3 (Composition API)
- Quasar Framework (CLI + Vite)
- Pinia
- TypeScript estricto
- Vue Router

## Requisitos

- Node.js `^22.12` o `^24`
- npm

## Instalación y arranque

```bash
npm install
npm run dev
```
